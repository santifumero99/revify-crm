Cómo funciona el dato

Cada comercial inicia sesión con su propio usuario. Los deals, visitas, estados y ventas que registra se guardan en la base de datos central.

El Admin agrega esa información por código postal, categoría, negocio y comercial. La facturación que ves aquí proviene de las ventas realmente registradas en el CRM.
